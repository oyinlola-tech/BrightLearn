# 📚 Education Blog

An engaging and user-friendly *frontend-only education blog* built with *HTML, CSS, and JavaScript*.  
It features 20 long-form educational articles covering study tips, teaching strategies, parenting guides, and modern trends in learning.  

No backend or database required — everything runs directly in the browser. 🚀  

--

## 🌟 Features 
- 🏠 *Homepage* with a grid of 20 article previews  
- 📖 *Individual Article Pages* (expanded, easy-to-read content)  
- 📱 *Fully Responsive* (works on mobile, tablet, and desktop)  
- 🎨 *Modern UI Design* with smooth animations and hover effects  
- 🔝 *Scroll-to-top button* and smooth navigation  
- 💡 *Pure frontend* (no backend functionality needed)
